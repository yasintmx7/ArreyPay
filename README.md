# Treat — group checkout prototype

Polished responsive interactive frontend. Open through a static HTTP server with `dist` as its root.

Includes overview, checkout creation, equal/custom contributions, cover remainder, simulated full settlement, expiry/refunds, merchant overview, and demo receipt downloads. Session data is intentionally temporary and resets on refresh. Links do not synchronize contributions across devices.

No wallet, smart contract, real funds, QR generation, persistent backend, authentication, or cross-chain integration is implemented. These are follow-up implementation work, not capabilities of this prototype. Every monetary interaction is explicitly labeled as a simulation.
